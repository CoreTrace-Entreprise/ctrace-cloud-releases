# ctrace-cloud releases

Release binaries of `ctrace-cloud`, the command-line client of [CoreTrace](https://app.coretrace.fr).
This repository holds published releases only; there is no source code here.

Each release carries the binaries for Linux, macOS and Windows, a `SHA256SUMS` file, its
Sigstore bundle and the build's SLSA provenance. Installation instructions:
https://app.coretrace.fr/docs
